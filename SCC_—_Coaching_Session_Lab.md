# SCC — Coaching Session Lab

A specialized tool for **Shining Clarity Coaching (SCC)** to analyze and compare coaching methodologies.

## Overview
This application allows coaches to engage in a simulated coaching session with an "ideal client" (powered by Claude AI). The session is designed to surface the coach's natural instincts, methodology, and behavior patterns.

## Features
- **Mock Coaching Session:** Interact with a self-aware, growth-oriented AI client.
- **Dual-Lens Analysis:** Analyzes the session based on the SCC Breakthrough Method.
- **Methodology Comparison:** Designed to help Scott and Cait triangulate their styles and build a combined coaching framework.
- **Worthiness-Centered:** Built on the core belief that worthiness is inherent, not earned.

## How to Use
1. Deploy this repository to **Cloudflare Pages**.
2. Open the live URL.
3. Enter the access PIN to begin.
4. Complete the mock session and follow-up questions.
5. Review and save the final methodology analysis.

## Technical Details
- **Engine:** Anthropic Claude API (`claude-sonnet-4-6`)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Security:** Direct browser access with required security headers.
